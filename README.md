# Clawpack_tutorial
This repository contains all the files used in my introduction to [Clawpack](http://www.clawpack.org/). The draft version is available here [en.ancey.ch/cours/doctorat/tutorial_clawpack.pdf](http://en.ancey.ch/cours/doctorat/tutorial_clawpack.pdf) (work in progress). The applications are centered on the equations met in hydraulics: linear and nonlinear advection, diffusion, the Saint-Venant equations (also called the shallow water equations).

1. Hyperbolic equation theory
2. The Saint-Venant equations
3. Introduction to Clawpack
4. Linear advection
5. Burgers' equation
6. Solving the Saint-Venant equations
7. Solving the Saint-Venant equations with scalar transport
8. Solving the Saint-Venant equations with a source term
